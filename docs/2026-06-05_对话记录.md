## 问题 1：VS Code Pylance 依赖警告

**用户反馈**：`assets/bug/001.png` 和 `002.png` 显示 Pylance 报错：
- "无法从源解析导入 'requests'" (`reportMissingModuleSource`)
- "无法解析导入 'webdriver_manager.chrome'" (`reportMissingImports`)

**诊断**：这是 VS Code Pylance 静态分析器的警告，说明当前选中的 Python 解释器环境里缺少这些包。不是代码 bug。

**建议**：
1. 确认 VS Code 的 Python Interpreter 选择正确
2. 在对应环境执行 `pip install -r requirements.txt`
3. 验证：`python -c "import requests; import webdriver_manager"`
4. 如仍报错，重启 VS Code 或 Reload Window

## 问题 3：找到 8 个容器但 0 个有效分组

**用户反馈**：首次运行成功进入页面，但日志显示：
```
找到 8 个 <div align='right'> 容器
提取到 0 个有效 PDF 分组
```

**用户提供线索**：
1. `assets/bug/003.png` — 终端日志截图
2. DOM 结构描述：`<div align="RIGHT">` 内包含 `<a>` 标签（有 `<p2>問題</p2>` / `<p3>解答</p3>`）和标题文本

**第一轮诊断（有误）**：
- 误以为 `<a>` 标签是空的
- 修改了 `_extract_pdf_groups()`，增加文件名提取作为 fallback

**用户纠正**：`<a>` 标签里确实有内容，如 `<a href="../../image/08/08111701.pdf" target="_blank"><p2>問題</p2></a>`

**第二轮诊断（正确）**：
- 在 `downloader.py` 的 `_extract_pdf_groups()` 中添加 INFO 级别诊断日志
- 运行后发现关键日志：
  ```
  [div 5/8] 未找到标题，文本: 問題　解答　14010202数と式13センター追試
  ```
- **根因**：标题正则 `[^\d]+大$` 硬性要求出处以"大"结尾，但实际出处是 `センター追試`、`センター試験`

**修复**：
- `parser.py`: `TITLE_PATTERN` 从 `^(\d{8})(.+?)(\d{2})([^\d]+大)$` 改为 `^(\d{8})(.+?)(\d{2})(.+)$`
- `downloader.py`: `TITLE_SEARCH_PATTERN` 从 `(\d{8}.+?\d{2}[\d]+大)` 改为 `(\d{8}.+?\d{2}[^\d]{2,})`
- 同时兼容旧格式（`近畿大`）和新格式（`センター試験`、`センター追試`）

**验证**：parser 单元测试全部通过（旧格式 + 新格式）。

## 问题 4：命名规则迭代

### 第一次尝试（废弃）

**用户诉求**：把"第几题"加入文件名。

**理解**：用户说 `"データの分析19"` 的 `19` 是第19题，`"数と式13"` 的 `13` 是第13题。

**修改**：文件名格式改为 `{year_full}{source}_{knowledge_point}_第{year_2digit}题_问题.pdf`

**示例**：`2019近畿大_データの分析_第19题_问题.pdf`

### 用户纠正

**用户反馈**："额，还是改回去吧。"

**新规则**：从 8 位序号中拆分：
- 前 2 位 → 年份（补全为 4 位）
- 后 6 位 → **识别码**（防止同名文件覆盖）

**最终文件名格式**：`{补全年份}{出处}_{知识点}_{识别码}_问题.pdf`

**示例**：
- `19112202` → 年份 `19` + 识别码 `112202` → `2019近畿大_データの分析_112202_问题.pdf`
- `14010202` → 年份 `13` + 识别码 `010202` → `2013センター追試_数と式_010202_问题.pdf`

**代码修改**：
- `parser.py` 的 `parse_title()` 新增 `code = serial[2:]` 字段
- `generate_filename()` 使用 `code` 生成文件名

**验证**：单元测试通过（旧格式 + 新格式 + 路径生成）。
