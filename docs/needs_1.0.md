该项目旨在设计一个能够自动爬取指定网站的PDF的桌面程序。

## 第一期（已完成）

### 核心功能
- 输入网站地址，自动将该站点中所有的PDF下载下来。
- 下载下来之后，按照一定的格式命名。
- 可以选择下载到哪个文件夹中。
- 不会对目标网站造成困扰（尽量做到）。
- 下载完成后可循环继续下载其他页面。

### 使用技术
- 使用 selenium 爬取。
- 使用 Chrome 浏览器。

### 交付物
- `codes/main.py` — CLI 入口（支持交互式输入）
- `codes/downloader.py` — Selenium 页面渲染 + PDF 下载
- `codes/parser.py` — 标题文本解析 + 命名生成
- `codes/requirements.txt` — 依赖清单
- `run.bat` — 根目录一键运行脚本
