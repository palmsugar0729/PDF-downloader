## 二、核心功能（第二期）

### 2.1 仅有答案的题目 → 截图功能

**背景**：部分题目只有答案 PDF 没有问题 PDF，v1.0 会直接跳过。

**方案**：
- 当检测到仅有答案 PDF 时，自动截取题目区域（题目截图 `<img>`）
- 将截图与答案 PDF 配对保存
- 命名格式：`{年份}{出处}_{知识点}_{识别码}_问题.png` / `_答案.pdf`

### 2.2 下载进度显示

**背景**：v1.0 只有开始/结束日志，用户无法感知下载进度。

**方案**：
- 终端显示实时进度条（如 `tqdm` 或自定义实现）
- 格式：`[=====>    ] 3/8  2023東京大_微分_050123_问题.pdf`

### 2.3 错误重试机制

**背景**：网络波动时下载可能失败，v1.0 会直接记录失败并跳过。

**方案**：
- 单个文件下载失败时自动重试，最多 3 次
- 重试间隔递增：2s → 4s → 8s
- 最终失败时记录到错误日志，供用户手动处理

### 2.4 批量 URL 输入

**背景**：v1.0 每次只能处理单个页面，用户需要反复输入。

**方案**：
- 支持传入 URL 列表文件：`python main.py --urls urls.txt`
- 或支持逗号分隔的多个 URL：`python main.py "url1,url2,url3"`
- 批量模式下每个 URL 处理完后统一输出总结

### 2.5 配置持久化

**背景**：常用设置（输出目录、延迟范围）每次都要重新输入。

**方案**：
- 本地配置文件 `config.json` 保存用户偏好
- 首次运行生成默认配置，后续自动读取
- 支持命令行参数覆盖配置值

## 三、可选功能（低优先级）

| 功能 | 说明 |
|------|------|
| GUI 界面 | 用 tkinter 做简单图形界面（拖放 URL、选择文件夹、显示进度） |
| 子页面自动发现 | 递归爬取当前页面链接到的子页面（需增加深度限制） |
| 下载历史记录 | 记录已下载的 URL + 序号，避免重复下载 |
