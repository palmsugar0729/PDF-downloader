## 第二期

### 核心功能

- [ ] **仅有答案的题目 → 截图功能**
  - 背景：部分题目只有答案 PDF 没有问题 PDF
  - 方案：自动截取题目区域图片，与答案 PDF 配对保存

- [ ] **下载进度显示**
  - 背景：当前只有开始/结束日志，无实时进度
  - 方案：在终端显示进度条（tqdm 或手动实现）

- [ ] **错误重试机制**
  - 背景：网络波动时可能下载失败
  - 方案：单个文件失败时自动重试 3 次，间隔递增

- [ ] **批量 URL 输入**
  - 背景：用户需要手动逐个输入不同页面的 URL
  - 方案：支持一次传入多个 URL，或读取 URL 列表文件

- [ ] **配置持久化**
  - 背景：常用设置（如输出目录、延迟范围）每次都要重新输入
  - 方案：本地配置文件（JSON/YAML）保存用户偏好

### 可选功能（低优先级）

- [ ] **GUI 界面** — 用 tkinter/PyQt 做简单图形界面
- [ ] **子页面自动发现** — 递归爬取当前页面链接到的子页面
