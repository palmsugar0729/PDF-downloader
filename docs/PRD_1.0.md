## 一、产品定位

一个 **CLI 命令行工具**，用于从指定网页自动下载数学题目的 PDF 文件（问题 + 答案），按规则智能命名并分类保存。

**目标用户**：开发者本人（个人工具）

---

## 二、核心功能（第一期 — 已完成）

### 2.1 输入与范围

| 功能 | 描述 |
|------|------|
| URL 输入 | 通过命令行参数传入或交互式输入单个目标页面地址 |
| 爬取范围 | **仅爬取给定页面**，不跟踪子链接、不递归 |
| 手动切换 | 用户手动提供下一个页面 URL，工具不自动发现新页面 |
| 循环下载 | 单次下载完成后询问是否继续，回答 y 则重新开始 |

### 2.2 PDF 下载规则

| 规则 | 描述 |
|------|------|
| 下载条件 | 必须同时存在「问题 PDF」和「答案 PDF」才下载 |
| 问题 PDF | 文件名不含 `s`，如 `19112202.pdf`，页面标记为 `<p2>問題</p2>` |
| 答案 PDF | 文件名含 `s`，如 `19112202s.pdf`，页面标记为 `<p3>解答</p3>` |
| 跳过规则 | 仅有答案 PDF 没有问题 PDF 的题目 → 跳过（后期可能加截图功能） |

### 2.3 PDF 命名规则

**标题格式**：`{8位序号}{知识点}{2位年份}{出处}`
- 示例：`19112202データの分析19近畿大`

**解析方式**：正则 `^(\d{8})(.+?)(\d{2})(.+)$`

| 部分 | 示例 | 提取方式 |
|------|------|----------|
| 序号 | `19112202` | 前 8 位数字 |
| 知识点 | `データの分析` | 序号后、年份前 |
| 年份 | `19` | 出处前的 2 位数字 |
| 出处 | `近畿大` | 任意字符串（不限于以"大"结尾） |

**文件命名格式**：`{补全年份}{出处}_{知识点}_{识别码}_{类型}.pdf`
- 类型：`问题` / `答案`
- 年份补全：`≤ 26` → `20xx`，`> 26` → `19xx`
- 识别码：8 位序号去掉前 2 位年份后的后 6 位（防止重名覆盖）
- 示例：`2019近畿大_データの分析_112202_问题.pdf`、`2019近畿大_データの分析_112202_答案.pdf`

### 2.4 保存路径

```
{输出目录}/{出处}/{年份}{出处}_{知识点}_{识别码}_问题.pdf
{输出目录}/{出处}/{年份}{出处}_{知识点}_{识别码}_答案.pdf
```

示例：
```
./downloads/近畿大/2019近畿大_データの分析_112202_问题.pdf
./downloads/近畿大/2019近畿大_データの分析_112202_答案.pdf
```

### 2.5 友好爬取策略

| 措施 | 说明 |
|------|------|
| 请求间隔 | 每次下载间随机延迟 1~3 秒 |
| 遵守 robots.txt | 下载前检查目标站点的 robots.txt |
| User-Agent | 设置合理的浏览器 UA |
| 速度原则 | 在遵守规则的前提下尽量快，不过度磨蹭 |

## 四、目标站点特征

- 站点：[mikiotaniguchi.com](https://mikiotaniguchi.com/main/sm/smmain.htm)
- 页面类型：纯 `document.write()` 动态生成，非服务端渲染
- PDF 所在容器：`<div align="right">`（兼容 `align="RIGHT"`）
- 每道题：序号（左）+ 题目截图（中）+ `<div align="right">`（右，含 PDF 链接和标题）

## 五、CLI 接口设计

```bash
# 交互模式（推荐）
python main.py

# 参数模式（脚本调用）
python main.py "https://target.com/page.htm" -o ./downloads
```

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | 否 | — | 目标页面地址（不传则交互式输入） |
| `-o, --output` | 否 | `./downloads` | PDF 输出目录 |
| `--delay-min` | 否 | `1` | 请求最小间隔（秒） |
| `--delay-max` | 否 | `3` | 请求最大间隔（秒） |
| `--no-headless` | 否 | — | 显示 Chrome 浏览器窗口（调试用） |
| `-v, --verbose` | 否 | — | 显示详细日志（DEBUG 级别） |
